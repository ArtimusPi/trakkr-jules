Testing API Endpoints (Advanced)

You can also test the API endpoints directly using tools like Postman or curl:

  • Parent Dashboard API: GET /api/dashboards/parent/<parent_id>
  • Kid Dashboard API: GET /api/dashboards/kid/<kid_id>
  • Create Chore: POST /chores/create
  • Assign Chore: POST /chores/<chore_id>/assign
  • Complete Assignment: POST /assignments/<assignment_id>/complete
  • Trigger Recurring: POST /chores/trigger-recurring
